## 👋 About Me

I'm **Roni** — a builder focused on **AI systems, full-stack products, automation, and practical software architecture**.

I like taking ambitious ideas and turning them into working systems: from the initial architecture and API design to the interface, deployment, automation, and long-term iteration.

A big part of my workflow is intentionally constraint-driven:

> **Build more with less. Automate aggressively. Ship what works.**

My current environment is heavily **Android + Termux + GitHub + cloud/free-tier infrastructure**, which means the development process itself is part of the engineering challenge.

## 🧱 Engineering Philosophy

### 01 — Systems over isolated features

I care about how components interact, not just whether an individual feature works.

### 02 — Constraints are useful

Limited hardware, limited budget, and limited infrastructure can force better architecture.

### 03 — Automation compounds

Anything repetitive should eventually become a script, workflow, service, agent, or reusable system.

### 04 — Production beats perfection

A working, observable, maintainable system is more valuable than an impressive unfinished prototype.

### 05 — Build with leverage

Use open-source software, cloud primitives, APIs, AI models, automation, and reusable components to multiply output.
